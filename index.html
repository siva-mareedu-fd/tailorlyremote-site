Selected project

TailorlyRemote: remote job discovery and résumé tailoring

An AI-assisted application that finds remote jobs open to candidates in India and tailors a Word résumé to each job without breaking its formatting or inventing claims. Founder and sole engineer; live in production.

  • Product and architecture. Designed, built and launched the application with .NET 10, React and TypeScript, PostgreSQL and Hangfire, a modular architecture and design documentation that includes 12 architecture decision records.
  • AI with document integrity. Provider-agnostic LLM integration with model routing and structured output validation. OpenXML is used to edit .docx résumés in place, preserving formatting, with checks that block unsupported claims. The model returns edits only, and every change is a diff the user approves.
  • Engineering and security. Automated tests, GitHub Actions, a typed OpenAPI client, authentication, rate limits and structured logging.
  • Production deployment. AWS EC2 running Docker Compose behind Caddy with automatic TLS, access through Session Manager with no SSH, encrypted nightly PostgreSQL backups to S3, and email through AWS SES.
